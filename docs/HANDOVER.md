## 1. このプロジェクトは何か
デザインスキル評価の結果（スコア＋コメント）を Figma フォーマットと同じ見た目で表示する
**オフライン・表示専用**の Web アプリ。データは Google スプレッドシートから
**CSV をダウンロードして取り込む**（評価入力・管理画面・DB は無し）。

- レーダーチャート（Mind / Creative / Business の3カテゴリ）に、本人スコアと
  **チーム平均（点線）**を重ねて表示
- 完全オフライン動作（外部 CDN・外部フォント・外部画像に実行時依存しない）
- 16:9 レイアウト。ブラウザの「印刷 / PDF」で資料化可能

参照:
- Figma フォーマット: https://www.figma.com/design/hMAzWHVOa4JFYgM90aNUrz/FD%E6%8B%85%E5%BD%93_%E3%82%A2%E3%82%BB%E3%82%B9%E3%83%A1%E3%83%B3%E3%83%88?node-id=21-3 （node `21:3`）

## 4. 手元（ローカル）での実行手順

### 4-1. 前提（最初の1回だけ）
**Node.js v18 以上（推奨 v20+）** が必要。未インストールなら https://nodejs.org/ の LTS を入れる。
```bash
node -v   # v18 以上ならOK
```

### 4-2. 取得して開発サーバ起動（一番手軽）
```bash
git clone https://github.com/wataru3110-4d/Internal.git
cd Internal
npm install        # 初回のみ・ネット必要
npm run dev        # http://localhost:5173 を開く（Ctrl+C で停止）
```
サンプル CSV（`public/data/assessments.csv`）が自動表示される。右上のドロップダウンで人物切替。

### 4-3. 自分のデータを表示
スプレッドシートを CSV でダウンロードし、いずれか:
- `public/data/assessments.csv` を**差し替えてリロード**
- 画面右上の**「CSV読込」**ボタンからファイル選択

### 4-4. オフライン環境向けビルド・配布
```bash
npm run build      # dist/ に静的出力
npm run preview    # 確認用ローカル配信
```
`dist/` 一式を対象 PC に持ち込み、静的サーバで配信、または `dist/index.html` を
ブラウザで直接開いて「CSV読込」で取り込む。16:9 資料は右上「印刷 / PDF」で出力。

### 4-5. テスト
```bash
npm test           # CSV 取込・集計の単体テスト（vitest）
```

## 6. 設計上の注意点（引継ぎポイント）
- **CSV は列名ではなく「列の位置」で対応**している（元シートが多段ヘッダー・改行入りラベルのため）。
  列順が変わると壊れるので、シート構成を変える場合は `csv-mapping.ts` を更新する。
- 先頭の見出し行は「氏名セルが空の行」を自動スキップする実装。
- `平均` 行があればそれをチーム平均に採用し、無ければメンバーから算出（欠損は0扱いせず除外）。
- 項目ラベルの正は `master-data.ts`（Figma 準拠）。CSV 側の表記揺れ
  （例: CSV「Basic / 課題解決力」↔ アプリ「Business / 課題解決思考」）は位置対応で吸収。

## 8. よくあるつまずき
- `npm install` 時の脆弱性警告は開発依存のもので動作に影響なし。
- `file://` で直接開くと CSV の自動読込（fetch）はブラウザ制約で失敗する → 「CSV読込」ボタンを使う。
  静的サーバ配信（`npm run preview` 等）なら自動読込される。
- 日本語が豆腐（□）になる場合はシステムに日本語フォントが無い → フォント同梱で解決。
